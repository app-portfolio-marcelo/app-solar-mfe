Machine Learning Performance Study

This application is a case study demonstrating the performance of different machine learning models that can be used for fraud detection. The dataset used for training and evaluation was obtained from Kaggle.

Dataset Overview

This dataset contains credit card transactions made by European cardholders in the year 2023. It comprises over 550,000 records, and the data has been anonymized to protect the cardholders' identities. The primary objective of this dataset is to facilitate the development of fraud detection algorithms and models to identify potentially fraudulent transactions.

Key Features:

  • id: Unique identifier for each transaction
  • V1-V28: Anonymized features representing various transaction attributes (e.g., time, location, etc.)
  • Amount: The transaction amount
  • Class: Binary label indicating whether the transaction is fraudulent (1) or not (0)
